# Google Drive Archive Extractor & Classifier

이 프로젝트는 구글 드라이브 내에 있는 압축 파일(`.zip`, `.tar.gz` 등)을 감지하여 다운로드한 뒤, 압축을 풀고 내부 파일들을 카테고리별(이미지, 문서, 코드, 미디어 등)로 분류하여 구글 드라이브에 다시 업로드해 주는 자동화 파이썬 스크립트입니다.

## 파일 구성

* `main.py`: 전체 흐름을 제어하는 메인 스크립트
* `gdrive_helper.py`: 구글 드라이브 API 연동 관련 유틸리티 (인증, 다운로드, 업로드, 폴더 관리 등)
* `classifier.py`: 로컬에서 압축 파일을 해제하고 파일의 확장자를 기준으로 카테고리를 분류하는 모듈
* `requirements.txt`: 프로젝트 구동에 필요한 라이브러리 목록

## 사용 방법

### 1. 관련 라이브러리 설치
터미널을 열고 프로젝트 폴더로 이동한 후 아래 명령어를 입력해 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 2. Google Cloud 인증 키 파일 (`credentials.json`) 준비
이 프로젝트를 실행하려면 구글 클라우드에서 다운로드한 OAuth 클라이언트 보안 비밀번호 파일이 필요합니다.

1. **Google Cloud Console**([https://console.cloud.google.com](https://console.cloud.google.com))에 로그인합니다.
2. 새 프로젝트를 생성하거나 기존 프로젝트를 선택합니다.
3. **API 및 서비스 > 라이브러리** 메뉴에서 **Google Drive API**를 검색해 활성화합니다.
4. **API 및 서비스 > OAuth 동의 화면**으로 이동하여 다음을 설정합니다.
   * User Type: **외부 (External)** 선택
   * 앱 정보 및 개발자 연락처 입력 후 저장
   * **범위(Scopes)** 설정: `https://www.googleapis.com/auth/drive` 권한 범위 추가
   * **테스트 사용자(Test users)**: 본인의 구글 계정 이메일을 추가하여 권한을 줍니다.
5. **API 및 서비스 > 사용자 인증 정보**로 이동합니다.
6. **사용자 인증 정보 만들기 > OAuth 클라이언트 ID**를 클릭합니다.
   * 애플리케이션 유형: **데스크톱 앱 (Desktop App)** 선택
   * 생성 후 리스트에서 해당 클라이언트의 다운로드 버튼(JSON 아이콘)을 클릭하여 다운로드합니다.
7. 다운로드한 파일의 이름을 **`credentials.json`**으로 변경한 뒤, 이 프로젝트 폴더(`C:\Users\exbxda13\gdrive-classifier`) 내부로 복사합니다.

### 3. 프로그램 실행
```bash
python main.py
```

### 4. 최초 실행 시 인증 과정
* 프로그램을 처음 실행하면 인터넷 브라우저 창이 열리고 구글 로그인 화면이 나타납니다.
* GCP OAuth 동의 화면 테스트 사용자로 추가한 계정으로 로그인합니다.
* 경고 화면("Google에서 이 앱을 검증하지 않음")이 나타나면 **고급 > ...으로 이동(안전하지 않음)**을 클릭한 후 권한 동의를 수락합니다.
* 성공적으로 로그인되면 로컬 디렉토리에 `token.json` 파일이 생성되며, 이후에는 다시 로그인할 필요 없이 실행됩니다.

## 동작 방식 설명

1. **압축 파일 검색**: 구글 드라이브 전체에서 `.zip`, `.tar.gz` 등의 확장자를 갖거나 MIME 타입이 압축 파일인 목록을 검색합니다.
2. **임시 다운로드 및 압축 해제**: 각 압축 파일을 컴퓨터의 임시 폴더(`tempfile`)로 다운로드하여 압축을 풉니다.
3. **카테고리 분류**: 압축 해제된 파일들의 확장자를 검사하여 아래 카테고리 중 하나로 할당합니다.
   * **이미지(Images)**: `.jpg`, `.png`, `.gif` 등
   * **문서(Documents)**: `.pdf`, `.docx`, `.xlsx`, `.txt` 등
   * **코드(Code)**: `.py`, `.js`, `.json`, `.html` 등
   * **미디어(Media)**: `.mp3`, `.mp4` 등
   * **압축파일(Archives)**: 하위에 포함된 압축 파일들
   * **기타(Others)**: 분류되지 않는 확장자
4. **구글 드라이브 업로드**: 드라이브 내에 `Extracted_[압축파일명]`이라는 폴더를 새로 만들고, 그 아래에 카테고리 폴더들을 생성하여 각각의 파일을 업로드합니다.
5. **원본 압축 파일 이동**: 처리가 끝난 압축 파일은 드라이브 내 `Processed_Archives` 폴더로 자동 이동되어 중복 처리를 방지합니다.
